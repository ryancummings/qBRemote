# Support

For app support, email [support@rads.icu](mailto:support@rads.icu).
If you have repository access, use [GitHub Issues](https://github.com/ryancummings/qBRemote/issues) for app bugs and feature requests.
For security problems, follow [SECURITY.md](SECURITY.md).

Include these details:

- App version
- iOS or iPadOS version
- qBittorrent version
- Steps that cause the problem
- Expected and actual results

Before you attach a screenshot or log, remove host names, IP addresses, passwords, cookies, and private torrent names.

For server configuration, use the [qBittorrent documentation](https://github.com/qbittorrent/qBittorrent/wiki).
This project does not provide server administration support.
