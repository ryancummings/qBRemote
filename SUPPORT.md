# Support

Use [GitHub Issues](https://github.com/ryancummings/qbRemote/issues) for a reproducible app bug or a focused feature request.

Include the app version, iOS version, qBittorrent version, and clear reproduction steps. Remove host names, IP addresses, credentials, cookies, and torrent names before you attach a screenshot or log.

This community repository does not provide private server administration or qBittorrent support. Use the qBittorrent documentation for server configuration problems.
